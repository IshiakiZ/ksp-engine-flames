# Engine Flames

A rocket engine's exhaust as burning gas, worked out as it leaves the nozzle and drawn as a true volume,
for Kerbal Space Program 1. It burns in the air of [Volumetric Explosions](https://github.com/IshiakiZ/ksp-volumetric-explosions),
which it needs. The short version is on the repository's front page.

* [The long description](The-long-description.md): everything the front page said before it was cut short, and what was tried on each system
* [How it works](How-it-works.md)
* [The re-entry fire](Re-entry-fire.md): the glow of a craft coming into an atmosphere fast (0.4.0)
* [Flames for other engines](Other-engines.md): which fuel each engine is taken as burning, and how a config changes it
* [Building it yourself](Building.md)
