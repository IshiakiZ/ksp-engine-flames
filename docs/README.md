# Engine Flames

A rocket engine's exhaust as burning gas, worked out as it leaves the nozzle and drawn as a true volume,
for Kerbal Space Program 1. It burns in the air of [Volumetric Explosions](https://github.com/IshiakiZ/ksp-volumetric-explosions),
which it needs. The short version is on the repository's front page.
